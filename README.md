# Flight Booking System

## Project Overview

This is a SQL-based Flight Booking System developed using MySQL. It stores and manages information about airlines, airports, flights, bookings, passengers, and tickets.

SQL queries are used to retrieve data and analyze booking, passenger, flight, and ticket information.

## Technologies Used

* SQL
* MySQL
* MySQL Workbench

## Database Tables

* Airline
* Airport
* Flight
* Booking
* Passenger
* Ticket
* Booking_Flight

## SQL Concepts Used

* CREATE DATABASE and TABLE
* INSERT and SELECT
* WHERE and ORDER BY
* GROUP BY and HAVING
* JOINs
* Aggregate Functions
* Subqueries
* CASE statements
* Views
* Indexes
* Stored Procedures

## Project Objective

The main objective of this project is to practice SQL, database design, data management, and data analysis using a real-world flight booking system.

## Skills Demonstrated

SQL, MySQL, Database Design, Data Analysis, Joins, Aggregate Functions, Views, Indexes, and Stored Procedures.
